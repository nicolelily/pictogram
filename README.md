# 2,000 Beagles at Ridglan Farms

A pictogram chart showing the status of 2,000 beagles at Ridglan Farms in Blue Mounds, Wisconsin — bred for laboratory experimentation.

Created for Day 2 (Pictogram) of the [#30DayChartChallenge 2026](https://github.com/30DayChartChallenge/Edition2026).
